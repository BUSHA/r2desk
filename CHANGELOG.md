## 1.2.2

- Native macOS file browser for Cloudflare R2 accounts and buckets.
- Folder tabs with saved locations, tab order, history, search, and selection.
- File and folder upload and download, file rename, folder creation, and deletion.
- Quick Look previews, sortable file columns, drag and drop, and keyboard shortcuts.
- Optional Transfers sidebar with progress, cancellation, and session history.
- Keychain storage for S3 credentials and support for R2 jurisdiction endpoints.
- Custom app icon and one native left sidebar toggle.
